# Solo Combo Combat Idea

## Status

This folder contains an early combat concept for a game in which the player controls one character and prepares custom Combos before battle. It is a discussion draft, not a final team decision.

The main design goal is to move much of the character-building depth from party composition into Action collection and Combo construction. Combat should then reward the player for choosing the right prepared Combo for the current enemy, resource state, and environment.

## Current Direction

The player prepares a limited set of Combos before combat. Every player turn uses one complete Combo; there are no separate basic attack, defend, or item commands outside the Combo system. A complete game may allow four to six prepared Combos, while an early prototype can begin with four predefined Combos.

Two battle-resolution models are still being considered:

1. The player resolves a complete Combo, followed by the enemy.
2. The player and enemy commit actions together, then resolve them on a shared Load-based timeline.

The second model is more distinctive and interactive, but it is also more difficult to implement, explain, animate, and balance.
